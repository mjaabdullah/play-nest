PlayNest
A modern online sports facility booking platform that allows users to discover and book sports venues like football turfs, badminton courts, swimming pools, and more.

Features
Browse and search sports facilities
Real-time availability checking
Easy booking and payment system
User dashboard for managing bookings
Facility owner admin panel
Responsive design for all devices
Tech Stack
Frontend: React, TypeScript, Tailwind CSS
Backend: Node.js, Express
Database: MongoDB
Authentication: JWT
